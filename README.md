# 🧮 push_swap – 42 School Project

**push_swap** is an algorithmic project from 42 School. The goal is to sort a stack of integers using a limited set of operations, in the fewest possible steps. The project focuses on algorithm optimization, memory management, and strict coding discipline in C.

## 📚 Objective
Write one programs:
- `push_swap`: takes an unsorted stack as input and outputs a sequence of operations to sort it.

## 🧩 Constraints
- Only specific instructions allowed (`sa`, `pb`, `ra`, etc.)
- Minimal number of operations required
- No use of standard libraries (except `write`, `malloc`, `free`)

## ⚙️ Skills Gained
- Data structure implementation (linked lists, stacks)
- Custom sorting algorithm design (indexing, radix sort, etc.)
- Operation count optimization
- Memory management and error handling in C

## 🛠️ Technologies
- Language: C
- Build system: `Makefile`

## 📸 Example

```shell
$ ./push_swap 3 2 1
